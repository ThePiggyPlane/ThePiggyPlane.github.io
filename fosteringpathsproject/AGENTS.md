# Fostering Paths — data contract for contributors (humans and agents)

Fostering Paths (`/fosteringpathsproject/`) is a static React site (Babel in the
browser, no build step) for current and former foster youth: career pathways,
the programs that lead to them, paid apprenticeships, foster-youth support
resources, scholarships, and a per-state guide to the rules that matter
(extended foster care, tuition waivers, ETV, Medicaid to 26, ILP).

Everything is plain JS files that call a `window.register*` function. There is
no server and no database. GitHub Pages serves the repo as-is.

## Layout

```
fosteringpathsproject/
  index.html                      loads libs, registries, base data, components
  lib/*.js                        registries + loader (do not edit for data work)
  data/careers/<id>.js            40 careers (window.registerCareer)
  data/programs.js                legacy curated CA Inland-SoCal programs (keep)
  data/apprenticeships.js         CA DAS apprenticeships (keep)
  data/national/resources.js      national-scope resources
  data/national/scholarships.js   national-scope scholarships
  data/states/index.js            manifest: which files exist per state (generated by tools/build-index.js)
  data/states/<ST>/guide.js       one window.registerStateGuide({...}) call
  data/states/<ST>/scholarships.js  window.registerScholarships([...])
  data/states/<ST>/resources*.js  window.registerResources([...])  (several files allowed)
  data/states/<ST>/programs*.js   window.registerPrograms({...})   (ipeds-generated + curated)
  data/states/<ST>/apprenticeships*.js  window.registerApprenticeships([...])
  data/states/<ST>/wages.js       window.registerWages({...})  generated from BLS OES (tools/gen_wages_oes.py)
  data/national/wages.js          national BLS figures for comparison (generated)
  data/onet.js                    career descriptions from O*NET (tools/gen_onet.py)
  tools/validate.js               node tools/validate.js  -> must print OK before committing
  tools/build-index.js            regenerates data/states/index.js from the files on disk
  tools/gen_programs_ipeds.py     programs for every state from IPEDS + College Scorecard
  tools/gen_wages_oes.py          wages for every state and metro from the BLS OES tables
```

`<ST>` is the two-letter USPS code in upper case (`CA`, `TX`, `DC`).
State files are lazy-loaded when a visitor picks that state, so size per state
matters less than correctness. National files load on every page.

## Rules that are not negotiable

1. **Never invent.** Every record must come from a page you actually opened
   (WebFetch, curl, or a dataset download). If you cannot confirm a field,
   leave it out (omit the key) rather than guessing. An empty state is better
   than a wrong phone number sent to a 19-year-old in crisis.
2. **Record provenance.** Every record carries `url` (the page a youth should
   open) and `verified` (`"YYYY-MM"` when you opened it). Add `source` when
   the record was derived from a dataset (`"ipeds-2023"`, `"ca-das"`).
3. **IDs are permanent.** Lower-case kebab-case, ASCII, unique across the whole
   site, prefixed with the state code or `nat`: `ca-nextup-rcc`,
   `tx-waiver-tuition`, `nat-fc2s-scholarship`. Never reuse or rename.
4. **Plain words, youth-facing.** `serves`, `provides`, `eligibility`, `notes`
   are read by a 17-to-26-year-old on a phone. Short sentences. No jargon
   without a gloss ("ILP (Independent Living Program)"). No em dashes.
5. **Only append to your own file.** Each contributor writes to the file paths
   it was assigned. Shared files (`index.html`, `lib/*`, `components/*`) are
   edited only by the integrator.
6. **Validate.** `node tools/validate.js` must pass. It checks schema, id
   uniqueness, lat/lng ranges, URL shape, and that referenced career ids exist.

## Schemas

### Resource  (`window.registerResources([ ... ])`)

A place or program a foster youth can contact. One record per program at one
location. A campus with both NextUp and Guardian Scholars gets two records only
if they are run by different offices with different contact info.

```js
{
  id: "ca-nextup-rcc",                 // required
  name: "Riverside City College NextUp", // required, what the youth will see
  org: "Riverside City College",       // required, parent organization
  category: "campus",                  // required, one of the list below
  state: "CA",                         // required, USPS code; "US" for national
  county: "Riverside",                 // CA/large states: strongly preferred
  city: "Riverside",                   // preferred
  address: "4800 Magnolia Ave, Riverside, CA 92506",
  lat: 33.9712, lng: -117.3802,        // numbers; only if you have the address
  url: "https://www.rcc.edu/...",      // required
  phone: "(951) 222-8000",
  email: "nextup@rcc.edu",
  serves: "Current and former foster youth, ages 16 to 25, enrolled at RCC.", // required
  ages: "16-25",                       // "18+", "16-25", "any"
  provides: "Priority registration, book vouchers, meal cards, counseling, laptop loans.", // required
  howToStart: "Walk into the EOPS office in the Bradshaw Building or email nextup@rcc.edu.",
  notes: "Limited slots. Apply the week you enroll.",
  tags: ["nextup", "eops", "books", "food"],  // free-form lower-case
  verified: "2026-10",                 // required
  source: "https://..."                // optional second source
}
```

`category` values:
`campus` (college/university foster youth support program) ·
`ilp` (county/state Independent Living Program, transition services) ·
`housing` (THP, THP-Plus, FYI vouchers, transitional housing, shelters for youth) ·
`health` (Medicaid/Medi-Cal enrollment help, mental health, clinics for foster youth) ·
`legal` (dependency attorneys, legal aid for foster youth, records/ID help) ·
`mentoring` (CASA, mentors, peer support, alumni networks) ·
`emergency` (emergency grants, basic needs, food, laptops, car repair) ·
`employment` (job programs, YouthBuild, Job Corps, workforce boards with foster set-asides) ·
`education` (K-12 liaisons, GED, tutoring, college access that is not a campus program) ·
`lgbtq` (LGBTQ+ foster youth specific) ·
`advocacy` (youth advisory boards, CYC chapters, policy groups a youth can join) ·
`agency` (the public child welfare agency itself, ombudsman, foster care hotline) ·
`other`

### Scholarship  (`window.registerScholarships([ ... ])`)

Money a foster youth can apply for. Includes ETV, tuition waivers, private
scholarships, and emergency grants.

```js
{
  id: "nat-fc2s-scholarship",          // required
  name: "Foster Care to Success Scholarship", // required
  provider: "Foster Care to Success",  // required
  type: "scholarship",                 // required: etv | waiver | scholarship | emergency | grant | loan-forgiveness
  scope: "national",                   // required: national | state | regional | campus
  state: null,                         // USPS code when scope is state/regional/campus, else null
  amount: "$2,500 to $5,000 per year", // required, plain text
  eligibility: "In foster care at 18, or adopted/guardianship after 16. Under 25. Enrolled full time.", // required
  ages: "under 25",
  deadline: "March 31 each year",      // "rolling", "varies by campus", or a date phrase
  renewable: true,
  url: "https://www.fc2success.org/...", // required
  howToApply: "Online application opens in January. Needs transcript and a foster care verification letter.",
  notes: "Also pairs you with a coach.",
  tags: ["books", "laptop"],
  verified: "2026-10"                  // required
}
```

### State guide  (`window.registerStateGuide({ ... })`) — one per state

```js
{
  state: "TX", name: "Texas",          // required
  agency: { name: "Texas DFPS", url: "https://www.dfps.texas.gov/", phone: "" },  // required
  extendedFosterCare: { toAge: 21, notes: "Must be in school, working, or in a program.", url: "" }, // required (toAge: 18 if none)
  tuitionWaiver: {                      // required; exists:false if the state has none
    exists: true, name: "Texas Tuition and Fee Waiver", covers: "Tuition and fees at public colleges",
    eligibility: "In DFPS conservatorship the day before 18, or adopted from DFPS, ...",
    ageLimit: "Enroll before 25", url: "https://..."
  },
  etv: { admin: "Texas Workforce Commission / ETV", maxAmount: "$5,000 per year", ages: "16 to 26", url: "https://..." }, // required
  medicaidTo26: { exists: true, name: "Former Foster Care Children (FFCC) Medicaid", url: "https://..." }, // required
  ilp: { name: "Preparation for Adult Living (PAL)", ages: "14 to 21", url: "https://...", how: "Ask your caseworker for a PAL referral." }, // required
  collegeApps: [{ name: "ApplyTexas", url: "https://www.applytexas.org/" }],
  stateAid: [                           // shows on the Cost page for this state; keep it to the 3 to 8 that matter
    { id: "tx-waiver", name: "Tuition and Fee Waiver", amount: "Tuition + fees", desc: "...", eligibility: "...", apply: "https://...", gotchas: "..." }
  ],
  firstWeek: [                          // 4 to 6 steps, this state's version of "do this first"
    { title: "FAFSA", body: "File as an independent student (foster youth question).", url: "https://studentaid.gov/" }

  keyOrgs: [{ name: "Texas Foster Youth Justice Project", url: "https://...", what: "Free legal help for current and former foster youth" }],
  notes: "Anything a youth moving to or from this state should know in two sentences.",
  verified: "2026-10"                   // required
}
```

### Program  (`window.registerPrograms({ id: { ... }, ... })`)

A credential at one institution. The legacy schema is kept; new fields are
added.

```js
"tx-houstoncc-paralegal": {
  name: "Houston Community College — Paralegal AAS",   // "Institution — Program" (em dash separator is parsed by the map)
  inst: "Houston Community College",                   // new: institution name
  tier: "cc",            // cc | csu | uc | private | public4 | trade  (csu/uc are CA only; use public4 elsewhere)
  state: "TX", region: "Houston", loc: "Houston",
  address: "...", lat: 29.7, lng: -95.3,
  sticker: 2500, realCost: 0,         // in-state tuition per year; realCost after typical foster-youth aid (0 when a waiver covers it)
  duration: "2 yr AAS",
  action: "Apply online (free)",
  url: "https://...",
  careers: ["paralegal"],              // new: career ids this program leads to
  cip: "22.0302",                      // optional
  source: "ipeds-2024",                // optional
  requirements: "", notes: "",
  verified: "2026-10",
  // generated school facts (IPEDS / Scorecard), all optional:
  level: "assoc",                      // cert | assoc | bach | grad
  grads: 42,                           // completions 2023-24
  public: true, forProfit: false,
  netPrice30k: 6100,                   // average net price, families under $30k, housing and food included
  gradRate: 17,                        // 150%-time graduation rate (shown for non-cc tiers)
  students: 45000,                     // total enrollment, fall 2023
  housing: true, childcare: false, applFee: 0,
  earnings: { yr1: 38000, yr1Pell: 36000, yr1Nat: 41000, yr4: 52000, yr4Nat: 55000 },
  phone: "(713) 718-2000"
}
```

### Apprenticeship  (`window.registerApprenticeships([ ... ])`)

Same shape as `data/apprenticeships.js` (DAS fields). Minimum for non-CA
records: `id` (prefix `<st>-`), `occupation`, `sponsor`, `state`, `loc`,
`address` or `lat/lng`, `websiteUrl` or `phone` or `email`, `verified`.

### Wages  (`window.registerWages({ ... })`) — generated, do not hand-edit

```js
{
  state: "TX", geo: "Texas", dataYear: 2025, source: "BLS Occupational Employment and Wage Statistics, May 2025 (...)", verified: "2026-10",
  careers: { nurse: { employed, fractionPct, oneInN, vsNational, medianWage, range50Low, range50High, range80Low, range80High, hourlyMedian, yearlyChange, yearlyChangePct, wageChange, wageChangePct } },
  regions: { "Houston": { geo: "Houston-Pasadena-The Woodlands metro", careers: { ... } } }   // keys match program regions
}
```
`data/national/wages.js` uses `state: "US"`. Suppressed BLS cells are simply absent; never estimate them.
Regenerate with `python3 tools/gen_wages_oes.py --csv <filtered OES csv dir> --cbsa <cbsa_list1_2023.xlsx>` after a new May release.

## Regions

CA regions (use exactly these strings in `region`): `Inland Empire`,
`Orange County`, `Los Angeles`, `San Diego`, `Central Coast`, `Central Valley`,
`Bay Area`, `Sacramento`, `North State`, `Sierra`, `Imperial`.
Other states: use the metro area name a local would say (`Houston`,
`Dallas-Fort Worth`, `Phoenix`), or omit.

## Workflow for a research agent

1. Read this file. Read your assignment. Open the authoritative directory first
   (state agency page, chancellor's office list, JBAY roster, FosterClub state
   page, NCSL table), then each individual program page.
2. Write records as you confirm them. Write the file early and append; do not
   hold 80 records in memory and lose them.
3. `node tools/validate.js` from `fosteringpathsproject/`. Fix every error.
4. Report back: file paths, record counts per category, and anything you could
   not verify (so the next shift can pick it up). Do not paste the data.
